Cómo añadir personajes y transformaciones

Busca en este archivo la parte de const personajes = [...].

Cada personaje tiene un bloque propio, y dentro de transformaciones metes todas sus formas.

Para las fotos, crea una carpeta llamada img y usa rutas como img/nara-majin.png.

Usa multiplicador como número (por ejemplo 50) y no como "x50".

El campo tipo te permite filtrar transformaciones por categoría.
