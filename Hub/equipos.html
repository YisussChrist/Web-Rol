Generador de equipos Pokémon

Rellena los datos del entrenador y sus Pokémon. Después copia el código generado para añadirlo al proyecto.

📖 Guía de formato

Cada entrenador puede tener hasta 6 Pokémon. Hay dos formas de añadirlos: Pokémon oficiales y Pokémon custom.

Pokémon oficial

Para un Pokémon oficial solo hace falta poner su ID de Pokédex, su nombre interno y sus tipos.

{
  id: 160,
  name: "feraligatr",
  types: ["water"]
}

Pokémon custom

Si el Pokémon es personalizado, marca la casilla Pokémon Custom y escribe solo el nombre del archivo de imagen. El generador añadirá automáticamente Pokemon Custom/. 

{
  id: 1126,
  name: "chattoroti",
  image: "Pokemon Custom/Chattoroti.png",
  types: ["normal", "flying"]
}
💡 Importante: para Pokémon custom, usa un ID nuevo si puedes, por ejemplo desde el 1000 en adelante. Si usas un custom, pásame también la imagen.
